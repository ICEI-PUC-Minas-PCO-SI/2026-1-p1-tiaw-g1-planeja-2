# Manual da Marca e Layout Padrão da Aplicação

## Visão Geral

Este documento apresenta o padrão visual adotado para toda a aplicação **PlanejaMais**, definindo a identidade visual, o layout, a responsividade, a iconografia e os principais componentes da interface. O objetivo é garantir consistência entre todas as páginas, proporcionando uma experiência intuitiva, moderna e agradável ao usuário.

# Conceito da Marca

A identidade visual do **PlanejaMais** foi desenvolvida para transmitir segurança, organização e facilidade no gerenciamento financeiro. O design busca oferecer uma navegação clara e objetiva, tornando o controle das finanças pessoais mais simples e eficiente.

### Personalidade da marca

- Confiança
- Clareza
- Organização
- Leveza
- Elegância discreta

### Estilo Visual

- Clean
- Minimalista
- Moderno
- Espaçado
- Calmante

---

# Logotipo

O logotipo do **PlanejaMais** foi criado para representar crescimento financeiro e evolução no controle das finanças.

Sua composição possui três elementos principais:

- **Símbolo do infinito:** representa continuidade, planejamento e evolução financeira.
- **Sinal de "+" (mais):** reforça crescimento, progresso e melhoria constante.
- **Seta ascendente:** simboliza desenvolvimento, conquistas e alcance de objetivos financeiros.

A combinação desses elementos comunica visualmente a proposta da aplicação: ajudar o usuário a organizar suas finanças e alcançar uma vida financeira mais equilibrada.

---

# Paleta de Cores

A identidade visual utiliza uma paleta baseada principalmente em tons de azul, complementada por cores de apoio para representar diferentes situações financeiras.

| Cor | Função |
|------|--------|
| 🔵 Azul Primário | Confiança, botões, links e ações principais |
| 🔷 Azul Secundário | Destaques, gráficos e elementos de apoio |
| 🟢 Verde | Receitas e sucesso |
| 🔴 Vermelho | Despesas e alertas |
| 🟡 Amarelo | Planejamento e atenção |
| ⚫ Escala de Cinzas | Fundo, textos, bordas e componentes |

O fundo principal utiliza um tom de cinza claro (`#F5F7FB`) em vez de branco puro, reduzindo a fadiga visual e melhorando a leitura durante o uso da aplicação.

---

# Tipografia

A fonte oficial da aplicação é **Inter**, escolhida por sua excelente legibilidade em interfaces digitais e dashboards.

A hierarquia tipográfica segue um padrão que facilita a leitura dos conteúdos:

- H1 – Títulos principais
- H2 – Títulos de seção
- H3 – Subtítulos
- Texto padrão
- Texto auxiliar
- Legendas

Os títulos utilizam espaçamento de 120%, enquanto os textos utilizam 150%, proporcionando maior conforto visual.

---

# Layout e Componentes

Toda a aplicação utiliza um sistema de layout baseado em:

- Grid de 12 colunas
- Largura máxima de 1200px
- Padding lateral de 32px
- Espaçamentos padronizados (4px, 8px, 16px, 24px, 32px e 48px)

Os principais componentes seguem um padrão único:

- Cards com cantos arredondados;
- Bordas discretas;
- Sombras suaves;
- Botões padronizados;
- Inputs modernos;
- Ícones minimalistas.

Esse conjunto garante consistência visual entre todas as telas.

---

# Responsividade

A interface foi desenvolvida seguindo o conceito **Mobile First**, adaptando automaticamente os componentes para diferentes tamanhos de tela.

Entre as adaptações estão:

- Sidebar transformada em navegação inferior em dispositivos móveis;
- Cards empilhados verticalmente;
- Redução dos espaçamentos laterais;
- Melhor aproveitamento do espaço disponível.

Essas adaptações garantem uma boa experiência tanto em computadores quanto em smartphones e tablets.

---

# Considerações Finais

O design do **PlanejaMais** foi planejado para transmitir profissionalismo, simplicidade e confiança, características fundamentais para uma aplicação de controle financeiro.

A padronização das cores, tipografia, componentes e layout proporciona uma interface consistente, intuitiva e de fácil utilização, fortalecendo a identidade visual da aplicação e melhorando a experiência do usuário.
